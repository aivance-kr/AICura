## 월간 요약

7월은 CD(SSH 배포)·CI 검증 게이트 등 개발·배포 환경 정비와 보안·SEO 보완이 중심이었다. 7/2~7/3 에 main 푸시 SSH 배포 워크플로우를 추가하고 운영 배포에서 드러난 문제(migrate 실패 감지, writable 권한)를 연달아 보강했으며, 7/3 에는 소셜 로그인 인증 우회 등 보안 취약점 4건을 처리했다. 7/9~7/13 에는 PHP CS Fixer·pre-commit/pre-push 훅·변경 영역 기반 CI 로 로컬 검증과 CI 를 일치시켰고, 7/30 에는 FCM 푸시 실연동과 CI 를 self-hosted 러너로 전환했다. 배포 PR 은 12회(7/2 4회, 7/3 2회, 7/4 2회 등)였다.
